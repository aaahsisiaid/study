## データ同期・バックアップ（両バージョン完全互換）
「データ入出力 / QR」ボタンから以下の方法で学習記録（「覚えた」）をエクスポート・インポートできます：
- **QRコード表示＆PNG保存**（外部ライブラリ不要のピュアJS生成。URL形式QRならスマホ標準カメラで開くだけで自動取り込み）
- **QR読み取り**（カメラ／QR画像ファイル。通常版は `BarcodeDetector`＋`jsQR` フォールバック、オフライン版は標準 `BarcodeDetector` のみで外部通信ゼロ）
- **同期コード（約121文字）のコピー＆貼り付け**（追加マージ／上書き選択可）
- **JSONファイルのダウンロード＆読み込み**
